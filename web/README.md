# RayLink Web

RayLink Web 由同源 Node.js 控制面直接提供。界面按四个工作区组织：

- **总览**：Runtime、有效用户、发布状态和 24 小时网络趋势
- **用户**：在创建或编辑用户时直接设置有效期、流量和节点范围；客户端统一使用通用订阅
- **策略**：路由、DNS、规则集和完整配置预览
- **系统**：主机拓扑、Runtime 状态、运行体检与诊断报告、主机诊断、每台主机的入站协议、证书、版本、备份、配置发布和历史回滚

用户中心登录、客户端配置下载以及现有用户、主机、协议、发布操作仍由同源 API 提供。
运行体检按需复核最新备份并汇总已有运行证据，缺失或过期数据标为待确认；不会自动测速或重启服务。详见 [功能设计](../docs/practical-features.md)。
页面不会展示独立“方案管理”或“服务管理”；流量、到期时间和节点范围归属于用户，协议归属于主机。

## 本地运行

项目不依赖前端构建工具，但数据与操作依赖同源 API。请从仓库根目录运行：

```bash
npm ci --ignore-scripts
npm start
```

随后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `index.html`：四个核心工作区的语义化结构
- `styles.css`：响应式设计系统与全部组件样式
- `app.js`：API 数据绑定、筛选、协议表单、安装、发布和回滚交互
- `DESIGN.md`：颜色、排版、组件和响应式规范

开发环境会初始化演示用户；生产环境不写入演示数据。Runtime 使用 `dry-run` 或
`systemd` 模式，具体部署方式见仓库根目录 `README.md`。
