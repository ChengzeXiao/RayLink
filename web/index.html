    使用指南

    让 Agent 开始工作

    1. 在客户端添加 MCP Server，传输方式选择 Streamable HTTP，填写上方 Endpoint，并设置 Authorization: Bearer <Token> 请求头。
    2. 先让 Agent 获取可用工具和系统状态，再执行权限范围内的用户管理或运维操作。
    3. 写入工具需要 requestId。同一次操作因超时而重试时复用原 ID；新的操作使用新的 ID，避免重复执行。
    4. 可从只读权限开始，为不同 Agent 分别创建凭据；不再使用时，在此撤销。
