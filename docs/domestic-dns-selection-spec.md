# 国内 CDN 的通用 DNS 选择

## 问题与证据

v0.2.45 已能把解析后的中国 IP 分到 DIRECT，但未被国内域名库收录的域名仍先通过代理使用海外 DNS。青藤之恋官方公开图片 `wx-love-img.afunapp.com` 的国内解析返回中国 CDN，海外解析返回境外 CDN。当前 Mac 的 Hako 请求记录确认图片命中 MATCH → 未分类流量 → 普通代理，三次公开图片请求耗时 1.85–2.87 秒。

原生 Mihomo 隔离测试另证实：即使海外 DNS 最终返回中国 IP，国内请求仍须等待该 DNS；注入 800 ms 延迟后完整 HTTP 请求耗时约 812 ms。这是可重复的配置缺陷证据，不是 iPhone 延迟测量。

## 本次范围

- 修改服务器生成的 Mihomo 与 Mihomo modern 完整智能订阅，供 Clash/Hako 使用，不增加逐 App 名单，不覆盖客户端订阅文件。
- 保留局域网、自定义、AI、明确海外、国内域名、中国 IP、未分类组的路由优先级；保留所有授权节点及 AI 手动选择/固定 Host 约束。
- 已知域名继续按现有 nameserver-policy 查询。未知域名通过两个国内加密 DNS 地址取得候选；仅全部 A 记录属于本版本受管 CN IP 集合时接受。非 CN、混合、私网/保留地址及立即失败响应回退到现有代理 DNS。
- 通过 CN IPv4 集合补集生成 fallback-filter.ipcidr，关闭依赖客户端 MMDB 的 geoip 判断；附加 IPv6 全拒绝项，维持现有 ipv6:false。计算结果在进程内复用，规则数据更新时自动派生，不另引入下载依赖。
- 智能判断只依据域名、DNS 与 IP，不能识别 HTTPS 正文，也不保证所有 CN 地址都是有效业务地址。无法分类仍进入可手选的未分类组，默认普通代理。
- 两个国内 DNS 地址属于同一供应商，缓解单端点故障，不代表跨供应商容灾。Mihomo 1.19.25 在两个国内 DNS 都不响应时共享约 5 秒查询预算，可能取消远端 DNS 回退；fake-IP 连接随后由未分类代理接收域名并远程解析。必须区分这种连接级回退与 DNS 查询成功，不声明零等待或全部故障无感恢复。
- 全局代理/直连模式、仅节点导出及其他客户端格式维持原语义。不得把本次 Mihomo 行为声明为 Egern/sing-box 的已验证能力。
- 验收覆盖生成配置的 fake-IP 入口和 IPv4 A 记录路径。Mihomo 1.19.25 在此入口对 AAAA/HTTPS 查询返回空答案；其 `/dns/query` 诊断接口可绕过 fake-IP 入口，因此不能据该接口的 HTTPS hint 推断实际 App 收到了相同答案。客户端自行覆写 DNS 模式不在本次已验证范围。

本规格在 Mihomo 智能模式下取代 `domestic-geolocation-routing-spec.md` 第 4 项关于未知域名 DNS 的限制：允许经过地址验证的国内候选，不允许无条件采用国内解析或根据一次连通成功永久学习直连。

## 验证边界

沿用已授权的完整订阅生成器及原生客户端请求边界。回归必须覆盖未收录国内域名、国内/国外 CDN 分叉、混合答案、无效地址、DNS 失败、远端 DNS 故障不阻断国内请求，以及 AI/海外/自定义优先级。验证两种 Mihomo 输出、无重复字段/引用错误、配置大小和本机 Hako 导入；部署后核对在线订阅与本机新请求。

iPhone App 内部图片请求需在该设备重新加载完整订阅后验收；Mac、隔离内核及服务器结果不能代替手机验收。
