# v0.2.36 网络修复验收

依据 [2026-10-02 体检](network-health-2026-10-02.md)，修复三个已复现的问题。用户已要求执行修复及服务器升级。保持用户身份、协议凭据、订阅地址、月度配额与历史账单，不再次重置用量。

1. 服务器出口解析：默认使用严格校验证书的 Cloudflare DoH，故障切换到 Quad9 DoH；不固定网站 CDN IP。提供系统 DNS 模式及自定义解析器、私域后缀。私域只交给本地 DNS；公共解析器均失败不回落到已知异常的系统 DNS。实际 Runtime 测试覆盖缓存、SERVFAIL、丢包、恢复、私域隔离、IP 直连。1.14 总查询超时 2 秒；1.13 使用原生查询超时，不能宣称同样恢复速度。
2. 测速：未知客户端默认继续使用传统 Mihomo/Clash 自包含格式，将各组预算统一为 12 秒，避免 5/8/12 秒混用导致同节点状态相互覆盖。新增显式 mihomo-modern 格式，仅用于 Mihomo >=1.19.1，共享 inline provider 健康结果，减少重复探测。不移除 TCP/UDP 分组、AI 稳定出口、默认故障回退与后台恢复能力，不以更换测速 URL 美化数字。真实核心验证严格 TLS、慢而可用路径、节点真实停止后的自动切换和恢复。
3. 本机 Caddy 证书：启动及默认每 15 分钟读取续期结果，仅处理当前已发布配置中 RayLink 托管的磁盘证书，不接管手工证书、inline、Reality 或 sing-box 自身 ACME。校验域名、有效期、密钥匹配及新旧关系，变化时整组更新并重启一次；真实握手/协议验证失败恢复旧文件并重新激活。并发串行、失败安全，暴露有效期及同步状态至界面、readiness、告警与 MCP，读写沿用权限体系。

上线验收：VPS-A 升级到新发布产物；验证数据库和凭据保留、主控/Runtime/计量/自然月状态、MCP、六类订阅、七协议严格 TLS 公网真实传输、新证书指纹、与升级前相同 URL 的延迟。Mac 诊断固定 en0 避免 TUN 绕路。手机客户端型号与内核未知，因此不能用 Mac 测试代替手机验收。
