# RayLink v0.2.34 — 自然月流量额度

用户流量额度现在按北京时间自然月自动重置：每月 1 日 00:00 开始新额度，主控停机跨月时在恢复启动后补执行。

## 升级行为

**首次从旧版本升级时，系统会立即归档现有用户的累计用量，并将当月已用流量清零。** 归档标记和重置在同一数据库事务中提交；重启、重试不会再次清零。升级器在迁移前备份应用及数据，发布前验证数据库兼容性。

每月额度、到期时间、停用状态、节点范围、账号密码、协议凭据及订阅地址均保留；剩余额度不结转。只有此前因用量耗尽而被排除且仍有效的用户恢复服务。

## 功能与修复

- 持久化周期、历史用量及人工调整记录；保留既有计量账本、日报和 Runtime 检查点。
- 管理界面和用户中心显示本月已用、每月额度及北京时间下次重置。
- 增加只读 MCP 工具 `users_usage_history`（共 53 个工具），并在用户查询及系统概况中返回周期信息。
- 增加管理员 `GET /api/users/:id/usage-history` 和本人门户 `GET /api/portal/usage-history`；权限与现有账号体系一致。
- 普通编辑不再写回表单中未修改的用量；明确调整用量携带 `usagePeriodKey`，跨月旧表单返回 `409 USAGE_PERIOD_CHANGED`。
- 重置后自动发布有效额度配置。远端节点离线时保留待同步状态和持续重试，后续配置替换继承重试保障，实际应用后才确认同步完成。

## 计量边界

Runtime 上报的是累计计数，无法精确还原采样间隔内每个字节的发生时间。跨月或首次启用后，对无法判断归属的首份累计样本先建立基线，再计量新增流量；可能少计一个采样间隔或停机期间归属不明的流量，避免旧流量重复扣入新月份。可确定的旧月增量补到历史，未来月份样本不会提前触发重置。

Runtime 仍为已批准的 sing-box 1.14.2 计量构建；本次不改变网络路由策略或宣称蜂窝网络吞吐提升。
