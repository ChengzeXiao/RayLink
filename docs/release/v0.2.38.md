# RayLink v0.2.38 — AI 全协议恢复与验证域名修复

修复 AI 自动出口在全部 TCP 候选失效后无法使用健康 UDP 协议恢复的问题。补齐 AI 网站入口和 Cloudflare 验证子域，增加实际加密协议的 WebSocket 长连接回归。Runtime 保持 sing-box 1.14.2 计量构建。

## 升级后操作

更新客户端**整份订阅**并重连，确认「AI 网站代理」选择「AI 稳定出口」。需要固定跨请求出口时，在共享测速格式的「AI 节点选择」内固定一个已验证节点；普通格式直接在 AI 组选择。客户端保留的旧策略不会自动被覆盖。Loon、Egern 节点订阅不含完整智能规则；相应规则须在客户端配置，Egern 可使用完整 Profile。

## 修复与覆盖

- Mihomo/Egern 的 AI fallback 保留全部兼容候选，TCP 在前、UDP 在后。全部 TCP 失效时，TUIC/Hysteria/Hysteria2 等健康路径能恢复新请求。sing-box 的高容差 URLTest 同样包含全部候选，保留健康的当前出口；它不提供严格有序 fallback。
- Cloudflare 验证改为覆盖 `challenges.cloudflare.com` 及其子域，包括官方列出的 `brunhild`、`hagen`。其他 Cloudflare 域名不强制进入 AI 出口。
- AI Studio、NotebookLM、Microsoft Copilot、GitHub Copilot、OpenRouter、Mistral、Cohere 专用域名加入 AI DNS 和路由。ChatGPT、Claude、Gemini、Grok、Perplexity、Poe 已有范围保持；共享平台只加入已核实的专用主机。清单与依据见 [AI 服务覆盖](../ai-service-routing.md)。
- 新增真实内核故障回放和 9 协议 WebSocket 门禁：严格 TLS、101 Upgrade、双向 256 KiB、空闲 70 秒后恢复、正常关闭及断流负例。生产 CI 和 Release CI 均执行。

## 保留与边界

从 v0.2.37 升级保留用户、协议配置、凭据、订阅链接、月度用量与历史，不重新清零，也不主动升级或重启代理 Runtime。未启用的公网协议不会自动开放端口。

所有可导出的协议都可被独立选择，但客户端自身须支持相应协议。公网启用的 7 协议共享同一个服务器出口 IP；切换协议不会改变该 IP 的地区或站点信誉。匿名 API 401、网页 403 验证页、HTTP 重定向均不等同于登录或模型生成成功；本版没有绕过人机验证或关闭证书校验。通用探测成功也不等于特定 AI 服务可用。

已有连接无法在真实网络断开后无损迁移，应用仍须重连；Clash 有序 fallback 可在首选恢复后把新请求切回。真实账号对话、API 收费请求与手机移动网络需要分别验收。具体证据见 [QA 记录](v0.2.38-qa.md) 与 [验收规范](../ai-all-protocol-spec.md)。
