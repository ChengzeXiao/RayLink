# RayLink v0.2.40 — 固定 AI 出口与分层诊断

将 AI 出口限制到指定 Host，并在界面与 MCP 中区分网络失败和网站响应。适用于单 VPS，也可用于已有多 Host 部署；无需新增服务器。sing-box 继续使用 1.14.2 计量构建。

## 固定 AI 出口主机

- 智能路由新增“AI 出口与检测”，按稳定 Host ID 绑定，改名不会改变绑定。
- AI 自动组和手选组保留所选 Host 的全部已授权、客户端兼容协议；同机可用协议仍能恢复后续连接。
- 固定主机缺失、没有授权协议或全部候选失败时，AI 流量不会自动切到其他 Host 或 DIRECT。普通代理组保持原策略；已有自定义规则和全局模式的优先级保留。
- 旧版管理客户端保存策略时，省略 `aiExit` 不会意外解除固定。
- 完整 sing-box、Mihomo legacy / modern、Egern Profile 支持该策略；仅节点订阅不能携带智能路由。

## 界面与 MCP 诊断

- 固定目标匿名检查 Claude、ChatGPT / OpenAI、Gemini、Copilot、Perplexity、Grok，显示 DNS、连接、TLS、HTTP 阶段与验证页、认证、权限、限流、超时等状态。
- 诊断不携带账号、API Key 或 Cookie，不调用模型，不跟随重定向；严格验证 TLS 和公网地址，限制并发、时间、响应大小并缓存重复检查。
- `routing_ai_status` 需要 `read` 权限；`routing_ai_check` 需要 `runtime.manage`。`routing_update` 可保存 `aiExit: { mode: "pinned", hostId: "local" }`；省略该字段保留原设置。
- 401、403、429 等诊断结果不会驱动自动切协议或重启服务。响应头过大单独标为检测限制，避免误判线路故障。

## 升级后操作

进入 **智能路由 → AI 出口与检测**，选择固定主机并保存，然后在客户端刷新**整份订阅并重连**。客户端保留的手动选择及全局模式可能覆盖路由，应核对“AI 网站代理”实际选择。

通用安装升级不会擅自为所有部署选择某台主机；管理员明确选择后生效。主控升级保留用户、权益、凭据、订阅链接、本月用量和历史，不再次清零，也不主动替换或重启 sing-box Runtime。

本次 VPS-A 已于 2026-10-04 升级并显式固定到现有 `local` 主机，线上 42 份订阅、MCP 权限与诊断、数据及 Runtime 保留检查通过。该部署无需重复选择主机；客户端仍须刷新完整订阅并重连。

## 验证范围

本版测试及部署证据见 [v0.2.40 验收记录](v0.2.40-qa.md)，早期功能细节见 [AI 出口与诊断 QA](../ai-egress-diagnostics-qa.md)。新增原生检查已进入生产与 Release 门禁，覆盖 sing-box 1.14.2、Mihomo 1.19.25 两格式的固定主机存在、缺失、无授权协议及故障隔离；Egern 覆盖配置回归。

匿名诊断仅代表主控服务器到目标的观察，不代表手机链路、真实登录、账户资格或模型调用成功。固定 Host 不保证 NAT 公网 IP 永不变化，也不能恢复整台 VPS 或 IP 不可达。精确连续失败计数、恢复冷却及客户端反馈仍属后续方案，本版未宣称具备这些能力。
