# RayLink v0.2.35 — TUIC 客户端兼容与自动配置修复

修复部分客户端使用 TUIC 时握手失败、显示 timeout 的问题：管理的 TUIC 服务端、订阅与公网探测统一协商 `h3` ALPN。之前仅用 sing-box 对接 sing-box 的测试未发现该兼容性差异，本版增加真实 Mihomo 跨客户端传输验收。

## 升级后请更新 TUIC 订阅

**更新客户端订阅后重新连接 TUIC。** 手动配置请填写 ALPN `h3`，保持节点的正确 SNI 和证书验证。旧版 sing-box 空 ALPN 配置无法连接已启用 h3 的服务端；仅修改客户端而不更新服务端也不能解决原问题。

发布新的 Runtime 配置时现有连接可能短暂重连。用户身份、协议凭据、订阅地址、额度和自然月用量历史保留；从 v0.2.34 升级不会再次清零用量。从更早版本升级仍会执行 [v0.2.34 首次自然月迁移](v0.2.34.md)。

## 功能与修复

- 为手动证书及 ACME 的 TUIC 服务端、sing-box 客户端明确设置 h3；Mihomo、Egern、Egern Profile 订阅同步输出。
- 公网协议探测继承服务端 ALPN，避免探测配置与真实服务不一致。
- RayLink Node 更新为 0.9.1，同步修复远端 TUIC 探针。已有远程主机请先在主机页更新 Node，再重新启用或检测 TUIC；0.9.0 的心跳、维护及升级能力继续保留，支持滚动更新，但其旧探针仍需升级才能修复。
- 自动安装使用涵盖入口协议的步骤名称，处理已启用协议所需的防火墙和监听验证。
- 增加真实 Mihomo 与 sing-box 的完整传输测试，以及去掉服务端 ALPN 后必须失败的对照测试；CI 固定 Mihomo 版本并校验下载哈希。

Runtime 保持已批准的 sing-box 1.14.2 计量构建，内核 BBR 与 TUIC 的 QUIC 拥塞控制仍是独立配置。本版不宣称移动网络吞吐提升。

详见 [修复规范](../tuic-compatibility-spec.md) 与 [发布 QA](v0.2.35-qa.md)。Linux AMD64、ARM64 产物通过发布流水线的生产测试和原生安装、更新及回滚后发布，附 SHA-256、manifest、SPDX 与构建来源证明。
