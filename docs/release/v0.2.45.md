# RayLink v0.2.45

修复部分国内 App 和网站因国内云服务器 IP 被误分类而绕行代理的问题。

- 国内 IP 兜底从运营商注册国家分类改为 DB-IP Country Lite 2026-10 的地理国家分类，覆盖 15,365 条 IPv4/IPv6 CIDR。未收录的域名解析到这些国内 IP 后可自动直连，无需逐个增加 App 名称。
- AI、明确国外域名及自定义规则仍优先；AI 手动节点、固定主机限制、未分类流量手动兜底均保留。不会因为地址位于国内就覆盖明确的代理规则，也不会把整个云服务商加入直连。
- sing-box、Mihomo、Mihomo-modern、Egern 完整订阅使用相同的审核数据。节点名称、协议参数、用户权限和流量额度不因本次升级改变。
- 数据包含来源版本、校验值、许可和完整增删报告；可离线复现并验证二进制与内嵌 JSON 一致。启动优先使用新版本自带数据，下载或校验失败保留有效版本，不自动接受未经审核的新数据。
- 新增原生内核回归：国内云 IP 直连、国外 IP 保留兜底、AI/国外/自定义规则优先，以及实际测试响应和连接记录。

各设备升级后需**刷新完整订阅并重新连接**，保持规则模式。仅节点订阅不含这些规则；系统代理和 TUN 权限仍由设备管理。地理位置数据可能有误差，App 也可能使用境外资源，因此不保证所有国内 App 都直连或加速。手机上的最终效果需用新连接记录核对，不能以服务器或 Mac 测试代替。

IP 数据来源：[DB-IP](https://db-ip.com)，CC BY 4.0；域名数据仍为已审核的 SagerNet 基线。本次无需更换 sing-box 1.14.2 Runtime，不迁移业务数据库。详见 [QA](https://github.com/Zane-SI/RayLink/blob/main/docs/release/v0.2.45-qa.md) 和 [数据来源与复现说明](https://github.com/Zane-SI/RayLink/blob/main/server/routing/rule-sets/README.md)。
