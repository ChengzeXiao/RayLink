## 已完成的定向验证

- SOCKS5、HTTP、HTTPS 原生 sing-box 1.14.2 上游矩阵：实际 VLESS、TUIC、Hysteria2 入站承载 TCP；AI 与 Google/普通网站分离；住宅断开/认证失败不回落 direct；AI 目标 UDP拒绝，普通 UDP保留；不受信 HTTPS 代理证书拒绝。
- 生成的完整 sing-box 客户端保留 AI 原始域名；Mihomo legacy/modern 既有 AI DNS 路由原生回归通过。
- 配置加密持久化、密码保留/清除、部署历史恢复、smart/local 锁、发布错误的当前和旧密码净化通过。
- Node 诊断实际连接隔离的三种代理及严格 TLS 目标；HTTP 407 与 AI 账户认证区分、代理凭据不传给目标、非受信 HTTPS 代理拒绝、取消握手后连接释放通过。
- 界面使用真实浏览器和隔离应用，覆盖三协议保存、密码操作、启停/刷新、dirty 输入保护、失败/模拟发布状态、代理认证与旧版本结果、登出，以及 1440px/390px 无横向溢出和页面错误。该浏览器 Runtime 是 dry-run，诊断响应是模拟数据。
