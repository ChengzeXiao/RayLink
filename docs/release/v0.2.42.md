# RayLink v0.2.42 — AI 出口二选一

原来的“AI 入口主机”和“固定 AI 上游”合并为一个 **AI 出口** 面板。选择一种方式，填写对应参数，一次保存并发布。

- **默认出口**：沿用服务器公网出口，多主机时可自动选择或固定主机，单主机沿用已有策略并隐藏选择；不使用住宅代理，已填住宅参数保留备用。
- **住宅代理出口**：仅展示 SOCKS5 / HTTP / HTTPS 参数，AI 专用网站、登录与 API 通过住宅上游。当前沿用 local 主机，Google 搜索、Gmail、YouTube、共享登录及普通浏览保持原出口。
- 切换设置使用事务；无效主机或配置不会留下部分修改。住宅故障不会自动换成服务器公网 IP，需要明确切回服务器出口。
- 界面区分正在编辑、已保存、最近成功发布和待发布；发布失败可重试，开发模式明确标为模拟。密码不回显，留空保留，清除需显式选择。
- 新 REST：GET/PATCH `/api/settings/ai-egress`，POST `/api/settings/ai-egress/publish`。新 MCP：`routing_ai_egress_get`、`routing_ai_egress_update`、`routing_ai_egress_publish`；写入需要 `runtime.manage` 和 requestId。旧上游及路由接口继续兼容。

升级保留当前选择和凭据，不自动启用住宅代理。sing-box 保持 1.14.2 计量构建；本次控制台升级不要求重启代理 Runtime。修改出口并成功发布后仍需刷新完整客户端订阅并重新连接。

没有真实住宅供应商时可以继续使用服务器出口。模拟代理、服务端发布和匿名检测不证明手机网络、住宅属性或 AI 账号登录/模型调用成功。验证记录见 [v0.2.42 QA](v0.2.42-qa.md)。
