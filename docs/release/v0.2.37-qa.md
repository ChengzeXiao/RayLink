# v0.2.37 AI 网络 QA

日期：2026-10-03（北京时间）。基线：`27d8389` / v0.2.36；需求为 AI API 偶发重新连接。原生测试使用 sing-box 1.14.2 与 Mihomo 1.19.25。

## 已复现与修复

| 问题 | 失败证据 | 修复后验证 |
| --- | --- | --- |
| Claude/OpenAI 部分依赖不跟随 AI DNS/出口 | `platform.claude.com` 等实际落普通解析及普通代理 | 两类 Mihomo 完整导出各 23 个域名的实际 DNS 与 HTTP 路由验证；包含相邻域不误匹配、用户覆盖 |
| Mihomo 精确 DNS 规则无效 | `domain:cdn.openaimerge.com` 被当作字面键，域名路由虽匹配但 DNS 仍普通 | 裸主机名规则通过原生 DNS 请求；用户自定义精确规则同修 |
| modern 默认 AI 绕过自动回退 | 内核把 provider 节点排在显式组之前；顶层选中 PRIMARY，PRIMARY 失效且 BACKUP 健康时实际 API 请求仍失败 | 顶层只列策略组，独立 AI 手选子组承载 provider 节点；故障后实际请求走 BACKUP |

`check:ai` 已加入生产门禁。测试调用公开订阅生成器和原生内核，保留导出的规则和策略组；网络夹具替换外部 DNS/代理端点，健康周期压缩为 1 秒。选择稳定性观察跨越 Mihomo 的 10 秒选择缓存。故障回退恢复首选时允许新请求回切，已建立的 SSE 必须继续。

本地 `npm run check`：600 项，599 通过、1 项原生共享 ACME 检查因未指定 1.14 Runtime 跳过、0 失败；CI 使用指定 Runtime 再执行完整门禁。三个核心/格式的 70 秒 SSE、故障恢复及跨缓存观察均通过，modern 独立手选通过真实控制器操作和请求验证；重建旧 provider 默认排序的负对照按预期失败。两轴独立审查发现的 modern 测试选择路径遗漏已修复并复测。

本地跳过的原生 ACME 项随后单独指定 1.14.2 Runtime 重跑通过。最终 CI 的 Node.js 22 和 24 均为 **600/600 通过、0 跳过**，两轴审查最终未解决问题均为 0。

## 公网与生产基线

下面测试在升级前 v0.2.36 上执行，说明未能直接重现用户的真实 API 断流，不作为修复前后性能提升证据。

- VPS-A 主控、Runtime、Caddy 活跃，Runtime 自上次发布以来无异常重启。6 小时窗口最多 15,000 条日志的截取中，有 3,728 条 AI 目标记录，未发现带 AI 目标的错误；截取不能证明全窗口无错误。
- 从 Mac 固定物理网卡 en0，加载生产完整传统订阅，用户凭据仅在内存替换为内部探测身份：43 次匿名 HTTPS 请求均有响应。API 正常返回 401，主页返回 Cloudflare challenge 403，明确区分传输可达与业务成功。
- 通过现有 7 个公网加密协议入口访问 VPS 上临时 loopback SSE 夹具：每协议一条 80 秒连续流、一条静默 70 秒后结束的流，14/14 完整收到首尾；无 TLS、鉴权或传输超时。夹具和临时 systemd 单元已清理。此测试不等价于 AI 模型实际生成。
- 本机 Mihomo → sing-box 严格 TLS 的 7 协议 70 秒静默续传全部通过；另一个 sing-box 双端测试中途断开负对照正确失败，7 协议 65 秒静默续传全部通过。
- 100 次无差异 reconcile 只产生初始发布；无变化证书同步不重启。没有发现固定 60 秒空闲中断，不引入未经故障复现验证的 keepalive 调参。

追加关联分析：将最多 25,000 条日志按连接 ID 关联，发现 7 条 ChatGPT TUIC 流在约 5 秒时被 remote 取消，以及 1 条 Hysteria 流在约 22.6 秒时被 remote 取消，错误码均为 0。服务器 inbound 中 remote 为客户端方向；正常关闭也会产生此信息，不能据此确认用户反馈的 API 重连根因。该结果与前面的“错误行本身不含 AI 域名”统计含义不同。

## 边界与升级

未使用用户 API 密钥，未执行收费模型调用，未完成手机运营商链路验收。通用健康 URL 不能检测 API 专属的 403/429/5xx，不能将“gstatic 正常”视作 AI 业务正常。真实上游中断、API 账户问题和物理网络断线仍需在客户端与服务端日志中关联。

升级保留用户、协议身份、订阅链接和月度计量。客户端需更新整份订阅；modern 固定节点入口移动到独立「AI 节点选择」，旧具体节点需要重选。旧「RayLink 智能」手选不会被无条件重置。
