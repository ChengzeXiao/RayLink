# RayLink v0.2.37 — AI 路由与 API 连接稳定性

修复 ChatGPT、Claude 依赖域名未跟随 AI 出口，以及 Clash 精确域名 DNS 配置未生效的问题。修复共享测速订阅默认选中具体节点、绕过 AI 自动故障回退的问题。Runtime 仍为 sing-box 1.14.2 计量构建。

## 升级后操作

在客户端更新**整份订阅**并重新连接。在「AI 网站代理」选择「AI 稳定出口」，或者固定一个已验证可用的节点。共享测速格式使用「AI 节点选择」进行独立手选，原先直接选择节点的用户需要在这个子组重新选定。客户端会记住旧策略组选项；此前选过「RayLink 智能」的用户不会仅靠订阅更新自动切回。使用 API 工具时，应确认工具确实使用该代理配置。

从 v0.2.36 升级保留用户、协议凭据、订阅链接、月度用量和历史记录，不重新清零，也不更换代理 Runtime。

## 修复

- Claude 的 `claude.com`、`claudeusercontent.com`，OpenAI 的 `oaistatsig.com` 纳入 AI DNS 与路由。补齐 7 个登录、验证及资源的精确域名；不将整个共享服务域名强制分流到 AI。
- Mihomo 的精确 DNS 规则改为内核支持的裸主机名，修复内置与自定义规则看似存在、实际不匹配的问题。保留自定义优先级、局域网保护与国内分流。
- 共享测速 Mihomo 的「AI 网站代理」默认实际进入「AI 稳定出口」，避免 provider 首个节点抢占默认选择。AI 专用手选子组独立于普通代理；真实故障可自动切换备用 TCP 节点，已有连接不因后台探测主动关闭。
- 增加原生内核回归：依赖域名的实际 DNS 与 HTTP 出口、相邻域名隔离、用户覆盖、SSE 连续传输、空闲后续传、故障切换、恢复及已有流连续性。

## 验收边界

通用测速成功不能证明某个 AI 服务可用。匿名 API 返回 401 只证明传输及鉴权端点可达；网页的 Cloudflare 验证、API 限流、账户或地区限制另行判断。本版没有通过关闭证书校验或增大 API 请求超时掩盖错误，也未使用用户 API 密钥产生收费调用。

Clash 的故障回退组会在首选节点恢复后把新连接切回；跨请求必须保持出口时请固定 AI 节点。自动选择不能跨越真实网络断开保存已建立的 TCP 流；客户端和 API SDK 仍需要按服务规则重试。原生模拟及 VPS 公网测试不代替手机移动网络、真实模型生成的验收。

具体检查结果见 [QA 记录](v0.2.37-qa.md)，范围见 [验收规范](../ai-network-repair-spec.md)。
