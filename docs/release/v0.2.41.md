# RayLink v0.2.41 — AI 专用上游代理

智能路由新增可配置的 SOCKS5、HTTP、HTTPS 上游，用于把 AI 网站、AI 专用登录和 API 请求接入固定住宅代理。默认关闭；不附带住宅 IP 或代理账户，也不要求第二台 VPS。sing-box 保持 1.14.2 计量构建。

## 界面与接口

- **智能路由 → AI 出口与检测 → 固定 AI 上游**：选择协议，填写地址、端口、用户名和密码；HTTPS 可设置 TLS 服务器名，严格校验证书。
- 支持保存并发布、停用、重试发布；区分已应用、待发布和开发模式模拟。发布可能重启 Runtime，失败时不显示为已生效。
- 密码留空保留，清除需显式操作；密码加密保存，部署历史中的住宅密码也加密，不进入客户端订阅、管理 API 或 MCP 回显。
- REST：GET/PATCH `/api/settings/ai-upstream`，POST `/api/settings/ai-upstream/publish`。
- MCP：`routing_ai_upstream_get`、`routing_ai_upstream_update`、`routing_ai_upstream_publish`；写入与发布需要 `runtime.manage`，支持已有 requestId 幂等机制。

## AI 与普通浏览分流

- 未配置或关闭时，Runtime 不增加住宅出站或相关 DNS/嗅探规则，直接检测不连接住宅代理；已停用代理的遗留密码失效也不阻塞正常读取和新配置发布。保存但未启用不会改变原有分流。
- 首版用于本地主控 `local` Host。启用时固定 smart / local，保留该主机已授权入站协议；停用上游保留既有主机固定。
- 只有已识别的 AI 专用域名进入住宅出口，包括 Claude、ChatGPT/OpenAI、Gemini 等 AI 网站和 API。Google 搜索、Gmail、YouTube、普通网站和未知 IP 目标保持原出口。
- 不把整个 Google、微软、共享登录、共享验证码/CDN、全部 HTTPS 或公共 DNS IP 划入住宅出口。加密请求无法仅凭共享域名区分用途，相关共享服务保留普通出口。
- AI TCP 使用指定上游，失败不配置 direct 回退；相关目标 UDP 拒绝以使用 TCP。TUIC/Hysteria 等外层入站协议保留，不等于关闭这些节点协议。
- sing-box 完整订阅保留 AI 原始目标域名，上游可自行解析；嗅探仅辅助识别。自定义 IP 规则为保持优先级和 DNS 重绑定保护，会先解析并固定目标 IP。IP-only/ECH 中无法恢复的 AI 域名不保证被识别，也不会为此把普通流量送住宅。

## 检测与使用

启用后，界面/MCP 匿名检查通过已配置代理连接固定 AI 目标，标明检测来源和配置版本，并区分代理认证失败与网站 API 认证。变更配置后不复用旧线路结果。探针不调用模型，不携带 AI 账号或 API Key；主控先预检目标公网地址，再固定目标 IP 并严格校验目标 TLS。

填写供应商参数并保存发布后，刷新完整订阅并重连。没有供应商参数时保持关闭。住宅属性、固定公网 IP、账号可用性、手机网络及长期稳定性需要真实接入后另行验证；代理检测成功不等于已发布 Runtime 或客户端路径验收。

验证记录见 [v0.2.41 QA](v0.2.41-qa.md)。
