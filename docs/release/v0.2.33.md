# RayLink v0.2.33

本版本将主控安装、SSH 节点接入、协议配置、订阅发布和后续维护串成完整流程，并修复用户保存、订阅启动和弱网分流中的可靠性问题。包含 sing-box **1.14.2 计量版**、RayLink Node **0.9.0**，提供 Linux AMD64 / ARM64 安装包。

## 自动安装与节点接入

- 首次安装自动补齐依赖、创建随机管理员、配置 Caddy/systemd、启用无需域名证书的 Shadowsocks、发布配置并核验服务及监听。初始账号保存在 `/etc/raylink/initial-login.json`，仅 root 可读。
- 输入 IP、SSH 端口、用户名及密码或私钥，即可接入新节点；任务覆盖安装、注册、BBR、协议、配置发布、计量和已有用户订阅验证，失败可定位并重试。
- 可使用已配置的 Cloudflare DNS 自动创建节点子域名、配置兼容协议及证书。主控提供域名环境变量和初始化向导；默认 IP HTTPS 无需购买域名。
- 修复 Linux 节点安装/升级的模块预检查误启动常驻服务、导致任务无法完成的问题。
- 修复安装中断后的恢复流程：保留已有身份、证书与加密密钥，核验安装归属，拒绝覆盖现有站点或已初始化数据。
- 修复 systemd 只读沙箱阻止 ACME 写入的问题，只开放独立证书目录；绑定域名的 Host 禁止直接修改 IP，避免旧 DNS 与订阅地址失配。

## 管理与维护

- MCP Server 使用 **Streamable HTTP + Bearer Token**，提供 52 个工具，按角色和 scope 管理用户、节点、配置及维护任务；写入审计、持久去重，重试不会盲目重复执行。
- 管理员可验证当前密码后修改登录名/密码；密码修改同步撤销相关会话与 Token。
- 主控与 Node 软件更新使用独立任务，支持状态持久化、重启后版本验证和失败回滚；应用更新保留正在运行的 Runtime/Cronet 配对。
- 节点页面展示真实 BBR 内核读数及采样时间，区分已启用、不支持、失败、离线和过期状态。
- 修复创建用户成功后刷新失败被误报、断线反复请求、管理员改名后旧账号被重新创建等问题。

## 网络质量与智能分流

- sing-box 默认优先 TCP 候选，保留可用 UDP 协议的健康准入与回退；AI 使用独立稳定出口，切换策略时保留既有连接。
- DNS 与国内、代理、AI 出口对齐；域名解析后执行 IP 规则，保留显式规则优先级；缓存持久化，DNS 超时 5 秒，过期缓存宽限 30 秒。
- 修复 sing-box 1.14.2 国内 DNS 空 direct detour 导致完整客户端无法启动的问题。
- IP 自签名部署下直接内嵌完整规则，避免远程规则下载的证书信任错误阻断启动；仍保留正常 TLS 校验。公开可信域名部署继续使用可更新的远程规则。
- 修复 Egern 选择器、离线规则完整性及规则更新一致性，明确区分主控预测和实际客户端测量。

## 验收与发布产物

发布流水线必须通过 Node.js 22 / Linux 生产验收，并在 **AMD64、ARM64 原生 Linux** 上完成实际安装、HTTPS 登录、完整订阅冷启动、Shadowsocks 传输/计量/撤销、MCP 鉴权、BBR 读数、systemd 目录权限及升级/故障回滚，才会创建 Release。PR 另覆盖 Node.js 24。

协议验收覆盖 17 种服务端配置、9 种对外协议、4 种 Reality 与 8 种 ACME 配置、9 种探针，以及 9 种协议真实传输和用户撤销。另包含 DNS 丢包恢复、智能路由、AI 稳定出口、故障切换和 4,000 次 API 内存稳定性测试。详细审查与复现方式见 [QA 记录](https://github.com/ChengzeXiao/RayLink/blob/v0.2.33/docs/release/v0.2.33-qa.md)。

附件包括每个架构的安装包、SHA-256、manifest、SPDX SBOM，以及一键安装脚本；全部附件生成 GitHub 构建来源证明。

## 安装与升级

全新 Debian/Ubuntu VPS，以 root 执行：

```sh
bash -o pipefail -c 'curl -fsSL https://github.com/ChengzeXiao/RayLink/releases/download/v0.2.33/install.sh | bash'
```

已有安装先备份数据目录、环境文件/订阅加密密钥、活动配置及 Runtime/Cronet，再通过系统更新或上述安装入口升级。远程 Node 0.7/0.8 需先执行一次 Node 程序升级，确认心跳为 **0.9.0** 后使用新维护能力。应用更新与 sing-box 更新相互独立。

**导出的 sing-box 配置要求客户端 1.14+**，请先升级客户端再刷新订阅；其他客户端继续使用对应订阅格式。默认 IP HTTPS 为自签名证书，浏览器、MCP 和订阅导入端仍须显式信任；SSH 自动接入会安全传递主控证书。

BBR 只作用于 TCP，不保证任何运营商吞吐提升；云安全组、真实公网 ACME 颁发/续期及手机蜂窝网络切换仍需在目标环境验收。系统更新指 RayLink 软件更新，不会升级 Linux 发行版或自动重启服务器。
