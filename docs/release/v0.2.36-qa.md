## 本地验证

- DNS：真实 sing-box 1.13.14 / 1.14.2，验证生成的路由和缓存策略。环境 DNS 端点替换为可控本地 UDP 夹具；保留解析、缓存、回退规则。主查询丢包后 1.13 约 10 秒、1.14 约 2 秒成功回退；私域失败不泄漏到公网，公共 DNS 双故障不回落系统 DNS，缓存、主源恢复、字面 IP 通过。生产 DoH TLS 与性能另在现场验证。
- 测速：真实 Mihomo 1.19.25 与 sing-box 1.13.14 / 1.14.2。现代格式 14 次启动 HEAD，传统格式 44 次；七协议严格 CA 验证传输 106,496 字节。两种格式均通过每次 HEAD 延迟 5.5 秒的慢路径；真实停用 TCP 入口后自动切换备用 TCP/UDP，后台自动恢复。测试只将周期缩短至 2 秒，未调用手动 delay 接口；错误 SNI 必须被 x509 拒绝。恢复旧 5 秒预算的负对照确实失败。
- TLS：受管证书实握手更新和回滚、失效/域名/密钥拒绝、手工资产隔离、同域手工入口不参与托管验收、并发去重、权限和回滚失败严重告警；受信 TLS 子进程验证新指纹与单次 restart。
- 配置编译覆盖本机、远程部署、preview 和候选配置；MCP scope 与管理员 API 权限沿用既有验证。
- 本地浏览器验证了移动宽度下证书面板可读、正确展示 dry-run 不支持状态、禁用同步操作，浏览器无错误。
- 本地完整套件 597 项：595 通过、1 跳过、1 条既有 Node 升级测试首次碰到子进程时限；该文件单独重跑 6/6 通过。新增代码定向回归和 1.14.2 协议配置、健康、Runtime DNS 与智能路由实测通过。Linux 完整套件仍作为发布门槛。
