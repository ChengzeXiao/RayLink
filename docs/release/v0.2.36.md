# RayLink v0.2.36 — 出口 DNS、测速与证书续期修复

修复服务器出口解析到远端 CDN 导致请求变慢、多个策略组测速预算不一致，以及 Caddy 续期后代理继续使用旧证书的问题。Runtime 保持 sing-box 1.14.2 计量构建。

## 需要做什么

升级服务器后，在客户端**更新整份订阅并重新连接**，仅点击闪电测速不会更新配置。现有 Clash/Mihomo 链接保持兼容格式；确认内核为 Mihomo 1.19.1 或更新版本的用户，可在订阅页选择「Mihomo 共享测速」。未知内核的 iOS 客户端继续使用原订阅入口。

证书或 Runtime 配置应用时代理会短暂重启，连接需要重连。用户、凭据、订阅地址、自然月用量及历史记录保留，从 v0.2.35 升级不会重新清零流量。

## 修复内容

- 出口默认通过严格 TLS 验证的 Cloudflare DoH 解析，失败自动尝试 Quad9；私域交给系统 DNS。支持系统 DNS 模式、解析器地址/TLS 名称与私域后缀覆盖。1.14 使用 2 秒单次 DNS 查询预算，避免异常系统 DNS 持续拖慢出口。
- 传统 Clash/Mihomo 订阅各组测速统一为 12 秒；显式 `mihomo-modern` 使用共享健康检查，减少重复请求，保留 TCP/UDP 分组、AI 稳定出口、故障回退及自动恢复。
- 本机受管 Caddy 证书启动时及每 15 分钟自动同步；校验新证书与密钥，应用后验证握手，失败回滚。系统证书页显示到期时间及同步状态，支持立即重试。手工证书、Reality 与 Runtime 自有 ACME 不被接管。
- MCP 增加 `runtime_certificates` 与 `runtime_certificates_sync`；`system_overview` 包含证书状态。同步要求 `runtime.manage` 权限，异常和临期状态纳入告警与体检。

## 配置与范围

环境变量见 `deploy/raylink.env.example`。`RAYLINK_RUNTIME_DNS_MODE=system` 可恢复系统解析；企业私域应加入 `RAYLINK_RUNTIME_DNS_PRIVATE_SUFFIXES`。`RAYLINK_TLS_RENEWAL_INTERVAL_MS` 默认 900000，0 关闭周期任务，但启动检查与手动同步仍可执行。

1.13 兼容配置仍保留原生约 10 秒 DNS 超时；1.14 当前兼容规则使用 `ip_accept_any`，会有弃用提示，后续大版本需再次迁移。共享测速格式要求 Mihomo 1.19.1+，不会根据不明确的客户端名称自动启用。以上修复不构成对所有运营商或手机网络吞吐的保证。

验收规范见 [网络修复规范](../network-repair-spec.md)，发布与现场结果见 [QA 记录](v0.2.36-qa.md)。
