# RayLink v0.2.46

修复 Clash/Mihomo 智能订阅中，部分未收录的国内 App 图片被海外 DNS 分配到境外 CDN、继而走代理的问题。

- 未知域名先取得国内加密 DNS 候选，仅 IPv4 A 记录全部属于受管中国 IP 范围时采用；其他结果回退代理 DNS。两个国内 DNS 地址缓解单端点故障，无需逐个补 App 名单。
- DNS 筛选与路由共用已审核 CN 数据，不依赖客户端自带的旧 GeoIP 数据库。AI、明确海外域名及自定义 DNS 规则继续优先，未知流量仍可手动选择兜底。
- 保留现有节点、AI 手动选择与固定主机限制；仅改变两种 Mihomo 完整订阅的智能模式。Egern、sing-box、仅节点订阅及全局代理/直连模式维持原语义。
- 加入原生内核回归，检查国内/国外 CDN 分叉、混合答案、DNS 失败、故障时连接回退、AI 隔离及配置兼容。

更新后需在每台 Clash 设备**刷新完整订阅并断开重连一次**，保持规则模式，让旧 DNS 缓存失效。无需新建节点或修改 AI 出口。

地理分类并非网站真实性验证，也无法保证每个 App 的资源都在国内。Mihomo 1.19.25 在两个国内 DNS 都不响应时仍可能等待约 5 秒；本次不升级客户端内核。手机 App 的最终效果必须在该手机上验收，不能以 Mac 或服务器结果代替。

详见 [设计与验证范围](https://github.com/Zane-SI/RayLink/blob/main/docs/domestic-dns-selection-spec.md) 和 [QA](https://github.com/Zane-SI/RayLink/blob/main/docs/release/v0.2.46-qa.md)。无需更换 sing-box 1.14.2 Runtime，不迁移业务数据库。
