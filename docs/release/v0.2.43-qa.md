## 国内 App 问题复现与修复

用户报告：Clash 规则模式，Wi-Fi 下牵手较慢。完整订阅此前遗漏控制台已有的国内后缀兜底，未被内置规则库收录的 `qianshouapp.cn` 因此先使用代理 DNS。

- 修复前原生断言失败：牵手 DNS 请求出现在 remote，而非 domestic。注入 450ms 海外 DNS 延迟后，牵手 fake-IP 连接耗时约 463–472ms。
- 修复后同参数原生复测：legacy redir-host、legacy fake-IP、modern fake-IP，各 42 个域名，共 126 条路径通过。牵手四个域名及未收录 `.cn` 均使用国内 DNS 与 DIRECT，fake-IP 连接约 9–12ms。
- 微信、淘宝、支付宝、抖音、B站、美团、京东、小红书等 35 个代表性域名仍使用国内 DNS 与直连；未将 `byteoversea.com` 等境外域名粗放归为国内。
- 未知非 `.cn` 域名保持原策略：先代理 DNS，再根据实际国内 IP 命中 `raylink-cn-ip` 直连。IPv6 策略保持不变。
- sing-box、Mihomo legacy/modern 和 Egern 完整订阅均覆盖国内兜底；显式自定义、AI、境外规则仍优先；非智能模式不插入兜底，IP 优先规则之后不重复解析。

上述毫秒数是隔离环境注入延迟的前后对照，不是用户手机、运营商或真实 App 端到端测速。
