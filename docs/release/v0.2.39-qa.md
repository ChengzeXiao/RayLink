## 本地真实核心与传输

- WebSocket：Shadowsocks、VMess、Trojan、VLESS、AnyTLS、Hysteria、TUIC、Hysteria2 使用真实 Mihomo → sing-box；Naive 使用 sing-box → sing-box。

## 未发布候选 v0.2.38 的门禁修正

正式发布复验 [37185853242](https://github.com/ChengzeXiao/RayLink/actions/runs/37185853242) 检出了旧 `route-failover-check.mjs` 的过期断言：TCP 全故障而 UDP 仍健康时，测试仍要求 AI 请求失败。固定等待 1500ms 使这一断言依赖探测时序，PR CI 因而未稳定检出。

修正后显式等待 AI 经 UDP 恢复，再停止 UDP，验证所有候选失败时 AI 与普通流量均禁止泄漏到 DIRECT。普通 TCP 默认仍保持自己的候选池边界；sing-box 不再被测试强制要求故障后只能选 TCP。原候选没有生成公开 Release 或部署；保留其 Git 标签，正式版本顺延 v0.2.39。

默认 AI 策略与 7 个启用协议分别访问 15 个网站/API 入口，共 **120/120 收到 HTTPS 响应，120/120 实际匹配 AI 路由和指定协议**。核心日志没有出现代理认证、证书或传输超时错误。所有测试使用内部探测凭据和独立客户端，绑定 `en0`。

| 目标 | HTTP 结果（每种协议一致） | 解释 |
| --- | --- | --- |
| Claude.ai、ChatGPT、Perplexity | 403 challenge | 验证页，不计为网站业务成功 |
| OpenAI、Anthropic、Mistral、OpenRouter API | 401 | 匿名认证响应，未执行模型调用 |
| Cohere API | 403 | 拒绝响应，未计为 API 成功，未推断账号/地区原因 |
| Gemini、Grok、Microsoft Copilot | 200 | 入口响应；未验证账号或对话 |
| GitHub Copilot `_ping` | 200 | 服务探测响应，未验证补全业务 |
| AI Studio、NotebookLM、Poe | 302/307 | 入口重定向，未验证后续登录 |

该矩阵不能证明验证挑战已经消失。客户端仍需更新整份订阅，真实账户、模型生成、验证码完成和移动网络体验仍需单独验收。
