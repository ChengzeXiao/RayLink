# RayLink v0.2.44

本版把客户端分流策略纳入服务器生成的完整订阅，减少逐设备维护覆写脚本的需要。

- 智能模式新增“未分类流量”手动选择组：国内域名与 IP 仍先直连，未分类流量默认普通代理，可在客户端改为直连。
- 路由策略新增“AI 节点选择方式”：手动固定节点或协议自动回退。手动模式只包含用户有权限的具体节点；固定 AI 主机时仍严格限定该主机，主机不可用不切往其他出口。
- 旧配置保留协议自动回退；旧客户端省略新字段保存规则时，不清除管理员已经保存的选择。HTTP 和 MCP 均支持新设置。
- Google 香港站明确使用普通代理；Mihomo 补齐局域网名称的 fake-IP 排除，保留原拨号域名绑定和国内 DNS 策略。
- 诊断标明未分类流量和手动 AI 节点由客户端选择，避免把服务器推断写成已确认的实际出口。

覆盖完整 sing-box、Mihomo、Mihomo-modern、Egern 配置；仅节点订阅不包含分流规则。节点名称和候选范围根据每个用户权限生成。

升级后在“策略 → 路由策略”选择 AI 节点方式并保存，刷新完整订阅、重新连接；核对新连接命中的规则、组和具体节点后，再移除旧的本地覆写。系统代理、VPN/TUN 权限及客户端手动选择仍由各设备控制。多个协议连接同一主机不代表不同国家；AI 账号登录和服务地区资格须单独验证。

控制面升级保留用户权益、凭据与流量；本次订阅适配不需要更换 sing-box 1.14.2 Runtime。测试与上线记录见 [QA](v0.2.44-qa.md)。
