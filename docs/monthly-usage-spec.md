# 自然月流量额度

本次需求：用户要求实现按自然月自动重置，并明确首次上线立即清零，开始本月新额度。审查基线：b602faab36ff81a000ad55cc93d467ce650bf285。

## 业务行为

- 所有 User Entitlement 默认按 Asia/Shanghai 自然月计量，每月 1 日 00:00 开始新周期。quotaGb 为每月额度，usedGb 为当期已用。
- 首次将旧版本数据库启用月度计量时，事务内先归档旧累计用量为 legacy，再清零。迁移标记持久化，重启或重复执行不再次清零。新建用户的显式初始用量保留在当前月。
- 月度归档和人工用量调整历史可查询，不删除既有日报/账本/计量检查点。历史只含用量及额度，不含密码、订阅密钥或 Runtime Credential。
- 月界自动执行；停机错过边界时启动补执行，常规读写和采样也应看见当前周期。跨年、闰年、重复执行及时间回退保持幂等，不能重新开启已结算旧周期。
- 月度重置后自动协调 Runtime 配置，使仅因额度耗尽被排除且仍在有效期、未禁用的用户恢复服务。禁用、到期、节点范围和凭据不改变；发布失败保留待同步状态并重试。
- 旧月份延迟样本计入历史，不扣当前额度。累计计数没有精确字节时间，跨月且无法确定边界的累计差额先建立新基线，宁可少计这一段，不把旧月流量扣入新月。相同周期后续差额正常计量，重复/乱序及多 Runtime 实例不重复收费。
- 新月边界前允许的未来时钟偏差不能提前重置或把未来月份数据扣到当前月。
- 显式人工调账可提供 usagePeriodKey；旧周期表单跨月后提交必须返回409 USAGE_PERIOD_CHANGED。普通用户编辑不回写未实际修改的usedGb。

## 公开接口与展示

- 用户对象包含 usagePeriod：key、timeZone、startsAt、resetsAt、lastResetAt。Bootstrap及MCP概况包含当前周期和同步状态。
- GET /api/users/:id/usage-history、GET /api/portal/usage-history、MCP users_usage_history 提供授权范围内历史，限量返回；用户门户只能看本人。
- MCP users_list/users_get显示当前月份、用量及下次重置；history工具只需read权限，遵守管理员角色交集。
- 管理界面与用户中心展示本月已用、每月额度、下次重置；显式采用北京时间格式。

## 验收边界

沿用项目公共Store、真实HTTP API和MCP边界测试；只模拟时钟与外部Runtime/systemd等系统边界，不用数据库内部断言替代业务行为。覆盖首次迁移、午夜边界、重启/停机、延迟样本、计数器重启、调账、权限和配置恢复。上线前备份并以生产数据库副本验证迁移；上线后验证7名既有用户和管理员凭据保留、legacy归档、当月新额度、订阅、MCP、Runtime与BBR。
